 СОЗДАНИЕ ШАБЛОНА АДМИНОМ — ПОШАГОВОЕ ОПИСАНИЕ
Шаг 1. Админ заходит в раздел шаблонов
Действие: Админ нажимает в меню «Шаблоны анкет» → «Создать шаблон»

Что видит: Пустую форму с двумя полями: «Название шаблона» и «Тип кузова»

Что делает: Вводит «Седан» в поле названия, выбирает из выпадающего списка «SEDAN», нажимает «Создать»

Система: Создаёт шаблон с ID=1, статус «Неактивен», сохраняет в БД. Открывается конструктор с пустым списком групп.

Шаг 2. Админ создаёт группы
Действие: Админ нажимает «Добавить группу»

Что видит: Модальное окно с полем «Название группы»

Что делает: Вводит «Кузов», нажимает «Сохранить»

Система: Создаёт группу с ID=1, привязанную к шаблону 1. Группа появляется в конструкторе.

Повторяет: Админ создаёт группы «Салон», «Двигатель», «Ходовая часть», «Документы»

Шаг 3. Админ создаёт пункты в группе «Кузов»
Действие: Админ открывает группу «Кузов» (клик) → нажимает «Добавить пункт»

Что видит: Модальное окно с полями:

text
┌─────────────────────────────────────────────────────────────┐
│ Добавление пункта                                           │
├─────────────────────────────────────────────────────────────┤
│ Название пункта *                                           │
│ [Состояние ЛКП________________________________]             │
│                                                             │
│ Описание                                                    │
│ [Оценка состояния лакокрасочного покрытия______]             │
│                                                             │
│ ☑️ Требовать оценку (1-5)                                   │
│ ☑️ Требовать фото                                           │
│ ☐ Требовать видео                                           │
│ ☑️ Обязательный пункт                                       │
│                                                             │
│                              [Отмена]  [Сохранить]          │
└─────────────────────────────────────────────────────────────┘
Что делает: Заполняет название «Состояние ЛКП», описание «Оценка состояния лакокрасочного покрытия», включает все чекбоксы (оценка, фото, обязательный), нажимает «Сохранить»

Система: Создаёт пункт с ID=1 в группе «Кузов»

Шаг 4. Админ продолжает добавлять пункты
Повторяет шаг 3 для пунктов:

«Царапины» (оценка + фото + обязательный)

«Вмятины» (оценка + фото + обязательный)

«Коррозия» (оценка + фото + обязательный)

Система: Пункты сохраняются с порядковыми номерами 1,2,3,4 в группе «Кузов»

Шаг 5. Админ меняет порядок пунктов (Drag & Drop)
Действие: Админ зажимает мышкой пункт «Коррозия» и перетаскивает его на позицию между «Царапины» и «Вмятины»

Система: Обновляет поле sort_order в БД для всех затронутых пунктов. Порядок отображения меняется без перезагрузки страницы.

Шаг 6. Админ создаёт пункты в других группах
Группа «Двигатель»:

Название	Оценка	Фото	Видео	Обязательный
Внешний вид двигателя	✅	✅	❌	✅
Работа двигателя	✅	❌	✅	✅
Утечки жидкостей	✅	✅	❌	✅
Группа «Документы»:

Название	Оценка	Фото	Видео	Обязательный
ПТС	❌	✅	❌	✅
СТС	❌	✅	❌	✅
Сервисная история	❌	✅	❌	❌
Шаг 7. Админ активирует шаблон
Действие: Админ нажимает переключатель «Активен» → «Сохранить»

Система: Устанавливает is_active = true. Шаблон становится доступен для диагностов.

📋 ЗАПОЛНЕНИЕ ОТЧЁТА ДИАГНОСТИКОМ — ПОШАГОВОЕ ОПИСАНИЕ
Шаг 1. Диагностик видит доступную заявку
Действие: Диагностик заходит в панель диагноста → «Доступные заявки»

Что видит: Карточка с информацией:

text
┌─────────────────────────────────────────────────────────────┐
│ 🚗 BMW X5 2022                                              │
│ VIN: WBSDE91070CZ12345                                      │
│ Заявитель: alex_bmw                                         │
│ Дата: 05.06.2026                                            │
│ Описание: Автомобиль в хорошем состоянии, требуется осмотр  │
│ [ФОТО1] [ФОТО2]                                            │
│                                   [ВЗЯТЬ В РАБОТУ]          │
└─────────────────────────────────────────────────────────────┘
Шаг 2. Диагностик берёт заявку в работу
Действие: Диагностик нажимает «ВЗЯТЬ В РАБОТУ»

Система: Меняет статус заявки с PENDING на IN_PROGRESS. Создаёт черновик отчёта. Перенаправляет на страницу выбора шаблона.

Шаг 3. Диагностик выбирает шаблон
Что видит: Карточки активных шаблонов:

text
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│ СЕДАН           │  │ ВНЕДОРОЖНИК     │  │ МОТОЦИКЛ        │
│ 48 пунктов      │  │ 52 пункта       │  │ 35 пунктов      │
│ [ВЫБРАТЬ]       │  │ [ВЫБРАТЬ]       │  │ [ВЫБРАТЬ]       │
└─────────────────┘  └─────────────────┘  └─────────────────┘
Действие: Диагностик выбирает шаблон «СЕДАН»

Система: Загружает группы и пункты из шаблона. Открывается страница заполнения отчёта.

Шаг 4. Диагностик заполняет пункты в группе «Кузов»
Что видит:

text

│    │ Комментарий...                                                 │  │

│                                                                         │

Действие: Диагностик нажимает на первую звезду в пункте «Состояние ЛКП» (ставит оценку 5)

Система: Звезды заполняются, значение 5 сохраняется в состоянии формы.

Действие: Диагностик вводит комментарий «Небольшая царапина на заднем бампере»

Действие: Диагностик нажимает «Добавить фото»

Что видит: Открывается системное окно выбора файлов

Действие: Выбирает 2 фото с компьютера

Система: Файлы загружаются в облако (S3/Cloudinary) через presigned URL. Появляются миниатюры. В БД сохраняются ссылки.

Шаг 5. Диагностик пропускает пункт
Действие: Диагностик решает, что пункт «Вмятины» не применим → нажимает «Пропустить»

Система: Оценка и комментарий блокируются. Пункт помечается как пропущенный.

Шаг 6. Диагностик видит прогресс
Что видит: Прогресс-бар вверху страницы обновляется: «4/8 пунктов заполнено»

Система: Прогресс рассчитывается автоматически при каждом изменении.

Шаг 7. Диагностик заполняет группу «Двигатель»
Группа «Двигатель» содержит:

Пункт	Оценка	Комментарий	Фото/Видео

Работа двигателя	-	(пропущено)	-
Утечки жидкостей	5	Сухо, без подтёков	1 фото
Шаг 8. Диагностик сохраняет черновик
Действие: Диагностик устал или ждёт дополнительных фото → нажимает «Сохранить черновик»

Система: Все заполненные данные сохраняются в БД. Статус отчёта остаётся DRAFT. При следующем входе диагност может продолжить.

Шаг 9. Диагностик продолжает черновик на следующий день
Действие: Диагностик заходит в «Мои отчёты» → находит отчёт со статусом DRAFT → нажимает «Продолжить»

Система: Загружает ранее сохранённые ответы (оценки, комментарии, ссылки на фото/видео). Открывается страница заполнения с уже заполненными полями.

Шаг 10. Диагностик завершает и отправляет
Действие: Диагностик заполняет все обязательные пункты → нажимает «Отправить на проверку»

Система:

Валидирует: все обязательные пункты заполнены? ✅

Обязательные фото загружены? ✅

Статус отчёта меняется на COMPLETED

Статус заявки меняется на COMPLETED

Отправляет уведомление админу: «Новый отчёт на проверку»

🔄 ИСПРАВЛЕНИЕ ОТКЛОНЁННОГО ОТЧЁТА
Шаг 1. Диагностик видит отклонённый отчёт
Действие: Диагностик заходит в «Мои отчёты» → видит отчёт со статусом REJECTED

Что видит в списке:

ID	Автомобиль	Статус	Действия
101	BMW X5 2022	❌ Отклонён	[Просмотр] [Исправить]
Шаг 2. Диагностик смотрит причину отклонения
Действие: Диагностик нажимает «Просмотр»

Что видит: Баннер с красной рамкой:

text
┌─────────────────────────────────────────────────────────────────────────┐
│ ❌ ОТЧЁТ ОТКЛОНЁН                                                       │
│ Причина: Не хватает фото двигателя. Пожалуйста, добавьте фото.          │
└─────────────────────────────────────────────────────────────────────────┘
А также: Пункт «Внешний вид двигателя» подсвечен красным, поле «Фото» пустое.

Шаг 3. Диагностик исправляет
Действие: Диагностик нажимает «Исправить»

Система: Создаёт копию отчёта с новым ID. Статус копии — DRAFT. Все ответы скопированы из отклонённого отчёта.

Действие: Диагностик добавляет 3 фото двигателя → нажимает «Отправить на проверку»

Система: Валидация проходит. Отчёт отправлен на повторную проверку.
